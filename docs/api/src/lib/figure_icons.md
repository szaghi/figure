# figure_icons

> figure_icons, the Lucide icons by name, as UTF-8 strings (generated by scripts/gen_icons.py: do not edit).

 The 2171 icons of Lucide 1.61.0 (ISC licence, third_party/fonts), whose font is merged into
 every text font FIGURE loads: an icon goes in any label, at any size, e.g. `ig_button(ICON_PLAY//' Run')`.
 Names are the Lucide names upper-cased, `-` turned into `_`, after `ICON_` (https://lucide.dev/icons/).

**Source**: `src/lib/figure_icons.F90`
