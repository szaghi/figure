# The Fortran path's plot seam (szaghi/figure#15 P10-P12)

The plot seam is `figure_implot` as a whole: on the Fortran path a plot's frame (P10), its items (P11) and its
subplots, links and drag tools (P12) are drawn by Fortran together, since an item draws into its frame. The current
implementation, over ImPlot, is `src/paths/imgui/plot/figure_implot.F90`; its path-independent part (where an item's
arrays are read, the scratch, the decimation's buffers) is `src/lib/figure_plot_series.F90`, used by both.

The Fortran frame grows here under its own module names (`figure_plot_frame`, ...), so `$PATH_FORTRAN` keeps the
current `figure_implot` until the Fortran one can replace it: every 2-D plot golden and recording equal on the
Fortran path. Its tests (`src/tests/fortran/`) draw the same plot with ImPlot and with the Fortran frame, in one
program, and compare the two pictures (`test_compare_image`, threshold 2).

**Ticks (the owner's choice (a), 2026-11-22):** the frame places ticks as ImPlot's `Locator_Default` does (the major
count from the axis length, `NiceNum`, ten labelled minors per major, the labels thinned when they overflow), so the
goldens stay. foresight's locator (gnuplot's: the step from the range alone) gives other ticks on every axis probed;
adopting it later is its own change, with regenerated goldens. Labels: `figure_plot_format`, a printf of one real
without allocation (glibc's output; at first foresight's `c_real`, which it reproduces with fixed buffers).

Progress, and what is left, are tracked on [#15](https://github.com/szaghi/figure/issues/15) (P10-P12), not here.

## Modules

- `figure_plot_frame`: a plot's begin and end, kept between frames (a table keyed by the title's ID), layout, axes
  and their limits and fit, ticks (their formats, ticks given), grid, title and labels, legend, input (pan, zoom, box
  select, menus), queries, the hooks the items call; subplots and aligned groups, axes linked across plots (a
  subplot's rows and columns, `pf_link_axis`'s named groups), axis tags.
- `figure_plot_items`: the items, as `implot_items.cpp` draws them; `pf_spec`.
- `figure_plot_transform`: how an item maps a value to a pixel (ImPlot's `Transformer1`).
- `figure_plot_locators`: ImPlot's locators (linear, log10, symlog, time) and the scale transforms.
- `figure_plot_format`: printf of one real (`%f %e %g %a`), integers and text into a buffer, without an allocation
  (glibc's output).
- `figure_plot_colormaps`, `figure_plot_colormaps_bundled` (generated by `scripts/gen_plot_colormaps.py`): ImPlot's
  maps, the bundled ones, the style's line colours.
- `figure_plot_colormap_files`: the user's colormaps read from files (`ip_load_colormap`'s CSV tables and ParaView
  JSON presets, their colour spaces), as `native/figure_colormap.cpp`.
- `figure_plot_colorbar`: the colour-scale legend (`ip_colormap_legend`, `ip_colormap_legend_edit`), as
  `native/figure_colormap.cpp`'s `fig_colormap_legend`.
- `figure_plot_field`: `ip_field_image`'s colouring and its texture cache, as `native/figure_field.cpp`.
- `figure_plot_tools`: the drag tools (lines, point, rectangle), as ImPlot's `DragLineX`, ... in `implot.cpp`.
- `figure_plot_hash`: Dear ImGui's string and integer hashes with a seed (ImPlot's item and drag tool IDs).

They draw through `figure_core` only (no ImPlot, no `figure_cimplot`). The C library's `pow`, `log10`, `asinh`,
`sinh`, `cos`, `sin` are called where ImPlot calls them, and products ImPlot does not fuse are kept in statements of
their own (nvfortran's FMA), so the three compilers draw the same pixels.

## Tests

`src/tests/fortran/figure_test_plot_frame*.F90`, built by the `-fortran` modes: each case draws one plot with FIGURE's
current API (`ip_*`, ImPlot) and with the frame in one headless window, 40 frames apart (a click of one pass must not
make a double click with the other's), and compares the axis ranges of every frame to the bit and the pictures with
`test_compare_image(threshold=2, max_failed=0)`. ImPlot normalises a line segment with `1/sqrt`, as the frame does
(native/patches/implot-0002: upstream takes SSE's `rsqrtss` estimate, whose bits differ by CPU vendor).
`figure_test_plot_frame_alloc` counts every heap allocation of a frame (the
program defines `malloc` and the like, glibc only) and expects none.

## The ImPlot calls the seam replaces

What `figure_implot` calls (76 ImPlot functions, through `figure_cimplot`) and the native C++ that calls ImPlot for
it, by step:

- P10, the frame: `ImPlot_BeginPlot`, `fig_plot_end`, `fig_plot_state`, the scope record's ends
  (`figure_scope.cpp`); `ImPlot_SetupAxes`, `ImPlot_SetupAxis`, `ImPlot_SetAxes`; `ImPlot_SetupAxisLimits`,
  `ImPlot_SetupAxesLimits`, `ImPlot_SetNextAxisToFit`, `ImPlot_GetPlotLimits`, `fig_plot_axis_constraints`;
  `ImPlot_SetupAxisScale_PlotScale`, `fig_plot_x_transform`; `ImPlot_SetupAxisTicks_doublePtr`,
  `ImPlot_SetupAxisFormat_Str`; `ImPlot_SetupLegend`, `ImPlot_IsLegendEntryHovered`, `ImPlot_BeginLegendPopup`,
  `ImPlot_EndLegendPopup`, `ImPlot_HideNextItem`; `ImPlot_GetPlotSize`, `ImPlot_IsPlotHovered`,
  `ImPlot_GetPlotMousePos`, `ImPlot_PlotToPixels_double`, `ImPlot_PixelsToPlot_Float`; `ImPlot_GetPlotSelection`,
  `ImPlot_IsPlotSelected`, `ImPlot_CancelPlotSelection`; the colormaps (`fig_colormap`, `fig_colormap_count`,
  `fig_colormap_name`, `fig_colormap_stops`, `fig_load_colormap`, `ImPlot_PushColormap_PlotColormap`,
  `ImPlot_PopColormap`, `ImPlot_SampleColormap`, `ImPlot_GetColormapCount`, `ImPlot_ColormapScale`,
  `fig_colormap_legend`, `fig_gradient_edit`); the style (`ImPlotStyle`: `figure_style_generated.cpp`,
  `figure_theme.cpp`, `figure_native.cpp`); `fig_dnd_plot_target` (`figure_dnd.cpp`); drawing in a plot
  (`figure_canvas.cpp`).
- P11, the items: `ImPlot_PlotLine_*`, `ImPlot_PlotScatter_*`, `ImPlot_PlotStairs_*`, `ImPlot_PlotStems_*`,
  `ImPlot_PlotShaded_*`, `ImPlot_PlotBars_*`, `ImPlot_PlotBarGroups_*`, `ImPlot_PlotErrorBars_*`,
  `ImPlot_PlotInfLines_*`, `ImPlot_PlotPieChart_*`, `ImPlot_PlotBubbles_*`, `ImPlot_PlotDigital_*`, `ImPlot_PlotText`,
  `ImPlot_PlotHeatmap_*`, `ImPlot_PlotHistogram_*`, `ImPlot_PlotHistogram2D_*`, `ImPlot_PlotImage`,
  `fig_field_image` (`figure_field.cpp`), `fig_texture_sampling`, `ImPlot_GetLastItemColor`, `fig_plot_annotation`.
- P12: `ImPlot_BeginSubplots`, `ImPlot_EndSubplots`, `ImPlot_BeginAlignedPlots`, `ImPlot_EndAlignedPlots`,
  `fig_aligned_open` (`pf_begin_subplots`, `pf_end_subplots`, `pf_begin_aligned`, `pf_end_aligned`);
  `fig_plot_link` (`figure_plot_links.cpp`; `pf_link_axis`); `ImPlot_DragLineX`, `ImPlot_DragLineY`,
  `ImPlot_DragPoint`, `ImPlot_DragRect` (figure_plot_tools' `pf_drag_*`); `fig_plot_tag` (`pf_tag`). The current
  path's own behaviours are kept where FIGURE adds them to ImPlot's (`ip_begin_subplots`' first-draw fit, a link
  group's first frame, `ip_drag_rect`'s ordering once released), and where ImPlot keeps state FIGURE did not ask for
  (an X2..Y3 axis stays linked after `pf_link_axis` stops); the frame's header names them.

The 3-D plots (`figure_implot3d`, ImPlot3D) are P13's seam, `src/paths/fortran/plot3d/` (its README); they use this
seam's `figure_plot_format`, `figure_plot_colormaps` and `figure_plot_locators`' transforms, read-only.
